El presente documento ofrece una evaluación técnica de las herramientas clave para la implementación de la capa 4 del proyecto **mag-re**. Estas herramientas proporcionan la infraestructura necesaria para la síntesis y producción de audio digital programático, permitiendo la automatización del flujo de generación musical mediante modelos de inteligencia artificial.

| **Criterio**                 | **pretty_midi**                                                                                                                                                            | **FluidSynth + SoundFonts (.sf2/.sfz)**                                                                                                                                                                     | **Pedalboard (Spotify)**                                                                                                                                                                | **Alternativa: Music21 + Librosa**                                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Función**                  | Manipulación, parsing y análisis de datos simbólicos MIDI (_piano-rolls_, tempo, notas).                                                                                   | Síntesis de audio mediante muestreo tabulado (_wavetable/sample-based rendering_).                                                                                                                          | Procesamiento de efectos digitales de audio (DSP) y alojamiento de plugins VST3/AU.                                                                                                     | **Music21:** Análisis musicológico profundo / **Librosa:** Extracción de características de audio.                                         |
| **Ventajas**                 | - API Pythonica intuitiva.<br><br>  <br><br>- Representación limpia de datos en arrays de NumPy.<br><br>  <br><br>- Método interno rápido para síntesis por ondas de seno. | - Renderizado directo de MIDI a `.wav` extremadamente rápido.<br><br>  <br><br>- Soporta estándares SoundFont ampliamente distribuidos.<br><br>  <br><br>- Alta fidelity según la librería SoundFont usada. | - Rendimiento C++ nativo muy rápido en Python.<br><br>  <br><br>- Interfaz moderna para cadenas de efectos (Reverb, EQ, Compression).<br><br>  <br><br>- Soporta plugins VST3 externos. | - Music21 analiza teoría musical (acordes, escalas, contrapunto).<br><br>  <br><br>- Librosa extrae espectrogramas, mel, MFCCs y _chroma_. |
| **Limitaciones**             | - No realiza síntesis realista de audio por sí solo.<br><br>  <br><br>- Sensible a archivos MIDI mal estructurados o corruptos.                                            | - Calidad del audio depende 100% de la calidad del archivo SoundFont (.sf2).<br><br>  <br><br>- Menor flexibilidad para modulación dinámica en tiempo real.                                                 | - No procesa simbología MIDI directamente (solo procesa buffers de audio float32/64 o eventos de control basales).                                                                      | - Curva de aprendizaje empinada (Music21).<br><br>  <br><br>- Librosa no está diseñada para síntesis en tiempo real.                       |
| **Reproducibilidad**         | **Alta**: Genera estructuras de datos deterministas independientes del sistema operativo.                                                                                  | **Media**: Depende del ejecutable/binario `fluidsynth` compilado en el sistema y del hash exacto del archivo `.sf2`.                                                                                        | **Alta**: Mismos parámetros DSP producen exactamente el mismo buffer de audio bit a bit.                                                                                                | **Alta**: Entornos puramente expresados en código Python con dependencias declaradas.                                                      |
| **Dependencias**             | `numpy`, `mido`                                                                                                                                                            | Binario C/C++ `fluidsynth` compilado a nivel SO, `pyfluidsynth` / `midi2audio`, archivo SoundFont (ej. GeneralUser GS).                                                                                     | `pedalboard` (C++ en PyPI con bindings CPython).                                                                                                                                        | `music21`, `librosa`, `scipy`, `soundfile`.                                                                                                |
| **Facilidad de Integración** | **Muy Alta**: Instalar vía `pip` sin dependencias complejas del sistema operativo.                                                                                         | **Media**: Requiere instalar binarios binarios del sistema (`apt install fluidsynth` o `brew install fluid-synth`).                                                                                         | **Alta**: Instalación limpia vía `pip install pedalboard`, sintaxis moderna y rápida.                                                                                                   | **Media-Alta**: Instalación por `pip`, aunque con dependencias numéricas densas.                                                           |
